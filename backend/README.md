# VietHeritage AI — Backend API Service

Chi tiết toàn bộ kiến trúc, hướng dẫn cài đặt, cấu hình môi trường và kịch bản test 19 Use Cases xem tại:
👉 [Root README.md](../README.md)

### Các lệnh nhanh:
```bash
# Cài đặt
npm install

# Seed dữ liệu văn học mẫu
node src/utils/seedLiterature.js

# Seed tài khoản Admin & cấu hình hệ thống
node src/utils/seedAdmin.js

# Khởi chạy server
npm run dev

# Chạy test kiểm thử 19 Use Cases
node test-usecases.js
node test-api.js
```
